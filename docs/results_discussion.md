# Results & Discussion Structure

## 1. Dataset
Number of tasks, languages, task categories, source benchmark.

## 2. Experimental Configuration
Models, prompt template, API configuration, hardware/software environment.

## 3. Correctness Results
Pass rates and failed-test analysis.

## 4. Completeness Results
Feature coverage and missing requirements.

## 5. Security Results
Number/severity of findings and representative patterns.

## 6. Maintainability Results
Maintainability index and code-quality metrics.

## 7. Explainability Results
Human/rubric-based explanation scores.

## 8. Usability Results
Questionnaire statistics.

## 9. Efficiency Results
Response time, token usage and cost if available.

## 10. Multi-Dimensional Comparison
Dimension-wise tables and charts.

## 11. Statistical Analysis
Means, standard deviations, confidence intervals and appropriate significance tests.

## 12. Discussion
Interpret findings against the research questions. Do not treat the highest score as universally 'best' without discussing the study's scope, weighting assumptions and limitations.

## 13. Limitations
Benchmark size, model version changes, API variability, evaluator subjectivity, security-tool coverage and scoring assumptions.
