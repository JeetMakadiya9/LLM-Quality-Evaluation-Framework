# Methodology

1. Select a programming benchmark.
2. Normalize tasks into a common schema.
3. Use identical prompts for every model.
4. Collect generated code, explanations, response time and token metadata.
5. Execute generated code against predefined tests.
6. Analyze completeness against task-specific feature rubrics.
7. Run security analysis with Bandit.
8. Analyze maintainability with Radon and code-quality tools.
9. Evaluate explanation quality using a documented rubric.
10. Collect user/developer usability ratings.
11. Calculate efficiency metrics.
12. Apply the pre-declared scoring methodology.
13. Store raw and derived results in SQLite.
14. Analyze results with Pandas.
15. Produce charts and an interactive dashboard.
16. Report limitations and findings without presenting sample data as real results.
