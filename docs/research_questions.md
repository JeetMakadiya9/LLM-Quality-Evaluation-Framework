# Research Objectives and Questions

## Objectives
1. Develop a reproducible framework for evaluating LLM programming assistants.
2. Evaluate generated solutions using multiple software-quality dimensions.
3. Compare model behavior using standardized programming tasks and prompts.
4. Analyze trade-offs between functional quality and efficiency.
5. Incorporate user/developer perception into the evaluation.

## Research Questions
RQ1. How do selected LLM programming assistants differ in functional correctness?
RQ2. How do they differ in completeness, security and maintainability?
RQ3. How does explanation quality vary across assistants?
RQ4. How do users rate usefulness and clarity?
RQ5. What relationship exists between response efficiency and quality?
